# Changes

## 0.1.0 — 2026-10-23

- No buttons or calendar cells have a fill. Only active navigation and calendar selections have a thin theme-accent border; inactive controls have no visible border. Clickable text is bright, static labels are muted, and a horizontal line separates days and months. Plugin styles override themes that fill every button.
- Replaced large folder cards with a compact Sunday–Saturday day calendar and a two-row month grid. Day dots represent the combined task and file count; a `+N` marker handles counts above five. Opening a day or month shows its counts and actions below the board.
- Month folders now start with the next month; the current month is never one of the 12 month tiles.
- English interface, settings, diagnostics, manifest description, and release documentation.
- Theme-aware controls using Obsidian CSS variables; light and dark browser-harness screenshots.
- Rolling 31-day board starting today, with all 43 tiles visible while a folder or supporting view is open.
- Click a day or month tile to add a task or upload a file; drag files and Tickler tasks to tiles.
- Month review with manual day assignment and calculated rollover of open day items.
- Markdown cards, read-only task index, external document import, `.eml` plain-text display, browser harness, and local release ZIP.
